# Circuit Automation

Circuit Automation is being built on the planned manufacturing path to define equipment and workcell profiles, robotic handling tasks, command journals, state reconciliation, lockout-tagout recovery plans and the platform-wide equipment input-surface clamp registry — operating deterministically without AI and never substituting software checks for hardwired emergency stops. Its current executable surface is repository validation tooling. It has no installed equipment controller, robotics runner, surface-clamp daemon or qualified record schema.

Circuit Automation is part of the **SC Neuromorphic Computing Systems** group (SC-NEUROMORPHIC-COMPUTING-SYSTEMS). The [group and project map](https://github.com/anulum/sc-neurocore/blob/main/docs/ecosystem.md) shows the whole programme and where this repository sits in it.
